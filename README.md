Restore the old timers GUI in BigTime.

BigTime has two timers GUIs. The original one allows editing/correcting timers and provides a way to add a new timer without losing track of time. However, the original one does have the weakness that it can undercount time if the page is not refreshed immediately prior to performing any actions. The original one is actually left in the site and functional but was unlinked from the GUI. So restoring it is a matter of adding the links back to it.

The new timer GUI has many restrictions, making it nonfunctional for actual users.
